# Safe Data Handling

Document ID: DEMO-003
Version: 1.0
Scope: Fictional portfolio procedures only.

## Minimum necessary data
Use only the information needed to investigate the issue. Prefer merchant and transaction references over personal details.

## Sensitive information
Do not enter full card numbers, card security codes, passwords or full bank account details into this assistant.

## Portfolio data
Use synthetic records and fictional procedures for development and demonstrations.

## Unknown answers
When the documents do not contain enough information, state that the answer cannot be established from the available sources.

## Operational actions
The assistant provides information only. It cannot retry payments, issue refunds, change account details or approve adjustments.
